# Төлөвлөгөө

Жил → улирал → сар → 7 хоног → өдөр гэсэн шатлалтай өдрийн ажлын төлөвлөгч.
Claude Design-аас гаргасан `Төлөвлөгөө Хуанли.dc.html` прототипийн гурван хувилбарыг
нэг React аппликэйшн болгож нэгтгэсэн.

## Ажиллуулах

Node.js 18+ шаардлагатай.

```bash
npm install
npm run dev
```

`npm run build` — production хувилбар `dist/` дотор угсарна.

## Дэлгэцүүд

| Таб | Прототип | Юу харуулах вэ |
| --- | --- | --- |
| **Хуанли** | 1a | 5 түвшний сэлгүүр (Жил / Улирал / Сар / 7 хоног / Өдөр), сонгосон түвшний харагдац, доор нь тухайн өдрийн чеклист |
| **Шатлал** | 1b | Сонгосон өдрийг Жил → Улирал → Сар → 7 хоногийн зорилготой холбож харуулах timeline. Карт дээр дарж дэлгэнэ |
| **Өдөр** | 1c | Бараан горим: цагийн зурвас, 14 хоногийн streak, дараагийн ажлын сануулга, өдрийн дүгнэлт |

## Харилцан үйлдэл

- **Дөрвөлжин нүд** — ажлыг дууссан/дуусаагүй болгоно.
- **Ажлын мөрийн бусад хэсэг** — засварын хуудас нээнэ (гарчиг, тэмдэглэл, огноо, цаг, зорилгын холбоос, зуршил, устгах).
- **Баруун доод + товч** — сонгосон өдөрт шинэ ажил нэмнэ.
- **Шатлал табын карт** — дарж дэлгээд «Зорилго засах»-аар тухайн түвшний зорилго, дэд алхмуудыг өөрчилнө.
- **Сануулга** — өнөөдрийн, ирэх 90 минутад багтах, дуусаагүй, цаг тавьсан ажил дээр гарна.
  «15 мин хойшлуулах» түр нуух, «Ойлголоо» тухайн ажлыг дууссан болгоно.

### Тэмдэглэл устгах

Гурван арга:

1. **Нэг нэгээр** — ажил дээр дараад засварын хуудаснаас «Устгах».
2. **Хэд хэдээр** — жагсаалтын толгой дахь **«Сонгох»** товчоор сонголтын горимд орно.
   Мөр бүр дугуй нүдтэй болж, дарж сонгоно. Доод самбарт «Бүгдийг сонгох»,
   сонгосон тоо, «Устгах» гарна. «Болих» эсвэл өдөр/таб солиход горимоос гарна.
3. **Багцаар** — толгой дахь **«⋯»** товчоор өдөр / 7 хоног / сар / бүгд гэсэн
   хамрах хүрээгээр нэг дор устгана. Тус бүрийн хажууд хэдэн тэмдэглэл устахыг
   харуулах ба баталгаажуулах асуулт гарна.

Сонгох болон багцаар устгах нь гурван таб дээр ч ажиллана.

## Гүйцэтгэлийн тооцоо

Бүх хувь (өдөр, 7 хоног, сар, улирал, жил, зорилгын бар) нэг эх сурвалжаас гардаг:
тухайн хугацаанд байгаа ажлуудын `дууссан / нийт`. Тиймээс аль ч түвшний тоо
өдрийн чеклисттэй үргэлж таарч байна.

Streak — өнөөдрөөс ухарч тоолсон, «ажилтай бөгөөд бүгд дууссан» дараалсан өдрийн тоо.

## Өгөгдөл

Бүх өгөгдөл хөтөч дээрх `localStorage`-д `tulubluguu.v1` түлхүүрээр хадгалагдана
(сервер байхгүй). Анх нээхэд өнөөдрийн бодит огноонд тааруулсан жишээ өгөгдөл үүснэ.
Хуанли табын доод талын «Жишээ өгөгдлөөр сэргээх» холбоосоор дахин үүсгэнэ.

Өгөгдлийн бүтэц:

```js
{
  version: 1,
  goals: [{ id, scope: 'year'|'quarter'|'month'|'week', key, title, items: [] }],
  tasks: [{ id, title, note, date: 'YYYY-MM-DD', time: 'HH:MM'|null, done, goalId|null, habit }],
  accent: 'oklch(...)'
}
```

`goal.key` нь `2026`, `2026-Q3`, `2026-09`, `2026-W38` хэлбэртэй — огнооноос
шууд тооцогддог тул зорилго тухайн хугацаандаа өөрөө наалддаг.

## Бүтэц

```
src/
  lib/date.js     огнооны туслах функцууд (7 хоног Даваагаар эхэлнэ, ISO долоо хоног)
  lib/seed.js     анхны жишээ өгөгдөл
  lib/store.jsx   төлөв, localStorage, гүйцэтгэлийн тооцоо
  components/     TaskRow, TaskSheet, GoalSheet, TabBar
  screens/        CalendarScreen (1a), HierarchyScreen (1b), DayScreen (1c)
  styles.css      прототипийн өнгө, хэмжээг хадгалсан классууд
```

Өнгө, фонт, радиус, зайг прототипээс яг тэр чигээр нь авсан. Цөм өнгө нь
`--accent` хувьсагч (`oklch(0.55 0.11 250)`) — өгөгдөлд хадгалагддаг тул
нэг мөрөөр солих боломжтой.
