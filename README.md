# Төлөвлөгөө

Жил → улирал → сар → 7 хоног → өдөр гэсэн шатлалтай өдрийн ажлын төлөвлөгч.
Claude Design-аас гаргасан `Төлөвлөгөө Хуанли.dc.html` прототипийн гурван хувилбарыг
нэг React аппликэйшн болгож нэгтгэсэн. **v0.2** — давтагдах зуршил, хайлт, буцаах,
тохиргооны таб, офлайн (PWA), мэдэгдэл.

## Ажиллуулах

Node.js 18+ шаардлагатай.

```bash
npm install
npm run dev
```

`npm run build` — production хувилбар `dist/` дотор угсарна.
`main` салбар руу push хийхэд GitHub Actions өөрөө угсарч GitHub Pages руу гаргана.

## Дэлгэцүүд

| Таб | Юу харуулах вэ |
| --- | --- |
| **Хуанли** | 5 түвшний сэлгүүр (Жил / Улирал / Сар / 7 хоног / Өдөр), сонгосон түвшний харагдац, доор нь тухайн өдрийн чеклист |
| **Ерөнхий** | Сонгосон өдрийг Жил → Улирал → Сар → 7 хоногийн зорилготой холбож харуулах timeline. Карт дээр дарж дэлгэнэ |
| **Өдөр** | Бараан горим: цагийн зурвас, 14 хоногийн streak, дараагийн ажлын сануулга, өдрийн дүгнэлт |
| **Тохиргоо** | Өнгө, горим, мэдэгдэл, зуршлын жагсаалт, **заавар**, өгөгдөл (export / import / сэргээх) |

## Харилцан үйлдэл

- **Дөрвөлжин нүд** — ажлыг дууссан/дуусаагүй болгоно.
- **Ажлын мөрийн бусад хэсэг** — засварын хуудас нээнэ (гарчиг, тэмдэглэл, огноо, цаг,
  давтамж, зорилгын холбоос, устгах).
- **Жилийн харагдац** — 12 сар тус бүр гараг, өдрийн дугаартай жижиг хуанлитай: ногоон = бүгд дууссан,
  улбар = зарим нь, саарал = хийгдээгүй, цайвар өнгөт = урьдчилан төлөвлөсөн, бүдэг = ажилгүй.
  Өнөөдрийн нүд тойрогтой. Карт дээр дарвал тэр сар руу орно.
- **Улирлын харагдац** — 3 сар бүтэн хуанлиар, өдрийн дугаар болон гүйцэтгэлийн зураастай.
  Өдөр дээр дарвал доорх жагсаалт тэр өдрийнхөөр солигдоно; сарын нэр дээр дарвал сарын харагдац руу орно.
- **Гүйлгэх мөр (`‹` `›`)** — идэвхтэй түвшний нэг нэгжээр урагш/хойш алхана: Жил дээр
  ±1 жил, Улирал дээр ±1 улирал, Сар дээр ±1 сар, 7 хоног дээр ±7 хоног, Өдөр дээр ±1 өдөр.
  Өнөөдрөөс хол явбал **«Өнөөдөр»** товч гарч ирж, нэг дарахад буцаана. Баруун дээд булангийн
  хувь нь харж буй хугацааны гүйцэтгэлийг харуулна (жилийн / улирлын / сарын / 7 хоногийн / өдрийн).
  Сарын алхам урт богино сарыг тооцно: 1/31-ээс дараагийн сар руу алхахад 3/3 биш 2/28 болно.
- **Баруун доод + товч** — сонгосон өдөрт шинэ ажил нэмнэ.
- **Толгой дахь 🔍** — бүх ажил, зуршлаас хайна. Олдсон мөр дээр дарвал тухайн өдөр рүү үсэрнэ.
- **Ерөнхий табын карт** — дарж дэлгээд «Зорилго засах»-аар тухайн түвшний зорилго, дэд алхмуудыг өөрчилнө.
  Зорилго **заавал байх шаардлагагүй**: гарчгийг хоосон орхиж хадгалах, эсвэл «Устгах» дарвал тухайн
  түвшин зорилгогүй болж, «Зорилго нэмэх» гэж харагдана. Устгасан зорилготой холбоотой ажил, зуршлын
  холбоос автоматаар салах ба гүйцэтгэлийн хувь хэвээр тоологдоно.
- **Сануулга** — өнөөдрийн, ирэх 90 минутад багтах, дуусаагүй, цаг тавьсан ажил дээр гарна.
  «15 мин хойшлуулах» түр нуух, «Ойлголоо» тухайн ажлыг дууссан болгоно.

### Зуршил (давтагдах ажил)

Шинэ ажил нэмэхдээ **Давтамж**-ыг сонгоно: `Нэг удаа`, `Өдөр бүр`, `Ажлын өдөр (Да–Ба)`,
`Сонгосон гараг`. Давтамжтай бол ажил биш **зуршил** болж хадгалагдана.

- Зуршил нь өдөр бүр шинээр хуулагддаггүй — нэг загвараас тухайн өдрийн мөр **үүсгэж**
  харуулна. Тиймээс 365 тэмдэглэл үүсэхгүй, зөвхөн нэг загвар хадгалагдана.
- Тухайн өдрийн гүйцэтгэлийг `habitLog` дотор `зуршил|огноо` түлхүүрээр хадгална.
- Зуршлын мөр дээр дарвал **загвар** засагдана (бүх өдөрт нөлөөлнө).
  Мөн «энэ өдрийг алгасах» болон «бүрмөсөн устгах» боломжтой.
- Бүх зуршлыг **Тохиргоо** табаас жагсааж харах, засах боломжтой.
- `Эхэлсэн` / `Дуусах` огноогоор зуршил хэзээнээс хэзээ хүртэл гарахыг заана.

### Тэмдэглэл устгах

1. **Нэг нэгээр** — ажил дээр дараад засварын хуудаснаас «Устгах».
2. **Хэд хэдээр** — жагсаалтын толгой дахь **«Сонгох»** товчоор сонголтын горимд орно.
3. **Багцаар** — толгой дахь **«⋯»** товчоор өдөр / 7 хоног / сар / бүгд гэсэн хамрах хүрээгээр.

Устгасан, алгассан, сэргээсэн бүх үйлдлийн дараа доод талд **«Буцаах»** мэдэгдэл 7 секунд
гарна — санамсаргүй устгасан бол нэг дарахад бүх өгөгдөл эргэж ирнэ.

## Мэдэгдэл

Тохиргоо → Сануулга хэсгээс асаана (хөтөч зөвшөөрөл асууна). Цаг тавьсан, дуусаагүй
ажлын өмнө `0/5/10/15/30/60` минутын аль нэгээр мэдэгдэнэ.

Хязгаарлалт: апп нээлттэй (эсвэл арын табанд) үед л ажиллана. Бүрэн хаасан үед мэдэгдэл
илгээхийн тулд push сервер хэрэгтэй болно.

## Офлайн (PWA)

`public/manifest.webmanifest` + `public/sw.js`-ээр апп утсан дээр суудаг, офлайн ажилладаг
болсон. Service worker нь угсарсан хувилбарт л бүртгэгдэнэ (dev үед кэш саад болохгүйн тулд).
Кэшийг шинэчлэх шаардлагатай бол `sw.js` доторх `CACHE` нэрийг өөрчилнө.

## Гүйцэтгэлийн тооцоо

Бүх хувь (өдөр, 7 хоног, сар, улирал, жил, зорилгын бар) нэг эх сурвалжаас гардаг:
тухайн хугацаанд байгаа **ажил + зуршлын** `дууссан / нийт`. Тиймээс аль ч түвшний тоо
өдрийн чеклисттэй үргэлж таарна.

**Зуршлыг өнөөдрөөр таслана.** Өдөр бүрийн зуршил жилийн эцэс хүртэлх бүх өдөрт
гардаг тул ирээдүйг «нийт»-д оруулбал жилийн гүйцэтгэл хэдхэн хувь болж, ирээдүйн
сарууд 0% болж харагдана. Тиймээс `habitStats` зөвхөн өнөөдрийг дуустал тоолно.
Хэрэглэгчийн өөрөө оруулсан ирээдүйн ажил бол тодорхой тоотой, санаатай төлөвлөгөө
тул хэвээр тоологдоно.

Streak — өнөөдрөөс ухарч тоолсон, «ажилтай бөгөөд бүгд дууссан» дараалсан өдрийн тоо.

## Огноо, шинэ жил

Хуанли, гараг, 7 хоногийн дугаар, улирал бүгд бодит `Date`-ээс тооцогдоно — кодод хатуу
бичсэн он байхгүй. Өндөр жил (2028-02-29), ISO 7 хоногийн жилийн зааг (2027-01-01 нь
2026-W53-д харьяалагдана), сарын эхний хоосон нүдний тоо бүгд автоматаар зөв гарна.

Апп нээлттэй байхад **өдөр солигдохыг ажиглана** (30 секунд тутам, мөн цонх идэвхжих бүрд).
Шөнө дунд, эсвэл шинэ жил гармагц «өнөөдөр» тэмдэглэгээ, сонгосон өдөр, streak автоматаар
шинэчлэгдэнэ — дахин ачаалах шаардлагагүй. Хэрэглэгч өөр өдөр зориуд сонгосон бол
тэр сонголтыг хөндөхгүй.

Шинэ жилд жил/улирлын зорилго хоосон болж «Зорилго нэмэх» гэж харагдана — зорилго нь
`2026`, `2026-Q3` гэх мэт түлхүүртэй тул хуучин жилийнх нь шинэ жил рүү дагаж орохгүй.

## Өгөгдөл

Бүх өгөгдөл хөтөч дээрх `localStorage`-д `tulubluguu.v1` түлхүүрээр хадгалагдана
(сервер байхгүй). **Анх нээхэд апп хоосон эхэлнэ** — жишээ өгөгдөл автоматаар бөглөхгүй.
Танилцах, туршихад жишээ өгөгдөл хэрэгтэй бол Тохиргоо → «Жишээ өгөгдлөөр сэргээх»
дарвал өнөөдрийн бодит огноонд тааруулсан өгөгдөл үүснэ.

Тохиргоо табаас JSON болгож татах, файлаас сэргээх, жишээ өгөгдлөөр солих, бүгдийг
цэвэрлэх боломжтой.

Өгөгдлийн бүтэц (schema v2):

```js
{
  version: 2,
  goals:  [{ id, scope: 'year'|'quarter'|'month'|'week', key, title, items: [] }],
  tasks:  [{ id, title, note, date: 'YYYY-MM-DD', time: 'HH:MM'|null, done, goalId|null }],
  habits: [{ id, title, note, time, rule: 'daily'|'weekdays'|'days', days: [0..6],
             goalId|null, from: 'YYYY-MM-DD', until: null, archived: false }],
  habitLog: { 'habitId|YYYY-MM-DD': 'done' | 'skip' },
  settings: { accent, theme: 'auto'|'dark', notify, notifyLead }
}
```

`goal.key` нь `2026`, `2026-Q3`, `2026-09`, `2026-W38` хэлбэртэй — огнооноос
шууд тооцогддог тул зорилго тухайн хугацаандаа өөрөө наалддаг.
7 хоног Даваагаар эхэлнэ (`days` массивт 0 = Даваа).

**Хувилбарын шилжилт.** v1 өгөгдөл (`task.habit === true`) автоматаар v2 рүү хөрвөнө:
ижил гарчиг + цагтай зуршлын тэмдэглэлүүд нэг загвар болж нэгдэж, дууссан өдрүүд нь
`habitLog` руу шилжинэ. Хөрвүүлсэн зуршил нь `Ажлын өдөр` давтамжтай гэж тооцогдоно —
шаардлагатай бол Тохиргоо табаас засна.

## Бүтэц

```
public/
  manifest.webmanifest, sw.js, icon-*.png   PWA
src/
  lib/date.js     огнооны туслах функцууд (7 хоног Даваагаар эхэлнэ, ISO долоо хоног)
  lib/model.js    схем, хувилбарын шилжилт, зуршлын дүрэм, өнгөний багц
  lib/seed.js     анхны жишээ өгөгдөл
  lib/notify.js   хөтчийн мэдэгдэл
  lib/store.jsx   төлөв, localStorage, гүйцэтгэлийн тооцоо, буцаах
  components/     TaskRow, TaskSheet, HabitSheet, GoalSheet, BulkSheet,
                  SearchSheet, SearchButton, Toast, TabBar, ListActions, SelectionBar
  screens/        CalendarScreen, HierarchyScreen, DayScreen, SettingsScreen
  styles.css      прототипийн өнгө, хэмжээг хадгалсан классууд
```

Өнгө, фонт, радиус, зайг прототипээс яг тэр чигээр нь авсан. Цөм өнгө нь
`--accent` хувьсагч — Тохиргоо табаас 6 өнгөний аль нэгийг сонгоно. Бүтэн бараан
горимд `.app.theme-dark` дотор CSS хувьсагчид дахин тодорхойлогдож бүх дэлгэц барааныг авна.
